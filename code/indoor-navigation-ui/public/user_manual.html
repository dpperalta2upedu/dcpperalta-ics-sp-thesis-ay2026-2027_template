Overview

How the Application Is Organized

Navigation Search

The home screen is the public navigation tool. Users enter an origin and destination, browse assisted suggestions, choose rooms from a floor based room list, and view indoor routes in 2D and 3D.

Admin Access

The top bar provides Admin Login. A successful login opens the builder and starts an 8-hour session. Logged-in users can switch between Navigation Search and Layout Builder.

Layout Builder

The builder is a Konva-based editor for map geometry and labels. It supports multi-floor editing, map drafts, history browsing, import/export, and publish actions that refresh the search experience after release.

Search Manual

How to Use Navigation Search

  1. Open the search page. The landing view shows the title Find Your Way Around Physical Sciences Building.
  2. Set an Origin. You can type a room name, choose a suggestion, or click Room List to pick from rooms grouped by floor.
  3. Set a Destination the same way. Destination room lists are filtered so only destination-ready spaces appear.
  4. Click SEARCH. If no origin has been provided yet, the app can fall back to Main Entrance for the first route search.
  5. Review the route map. The UI focuses the destination floor, displays floor and wing context, and shows route guidance for single-floor or multi-floor travel.
  6. Use the route controls to zoom, reset the view, switch floors, inspect the destination in 2D Full View, or open the route in 3D View.
  7. Start another search when needed. If you are chaining trips, the app can ask if the previous destination should become the new origin.

Route Map

Interactive Map Features

2D Route View

The main map renders the route with destination emphasis, origin markers, floor badges, wing overlays, and route motion. The control block labeled Current Floor & Wing lets users jump between floors and refocus the route view.

For multi-floor directions, the map shows a clear Proceed to Floor N prompt when the route requires a floor change.

2D Full View and 3D View

2D Full View opens a larger destination focused floor modal. 3D View opens a full screen route scene with a legend for origin and destination plus drag and pan helpers.

The 3D scene is built from the current published layout, so builder changes are reflected after a successful publish.

Zoom, Reset, and Thumbnails

Users can zoom with the mouse, reset the zoom, and inspect floor thumbnails for route overviews. On longer multi-floor routes, mini floor previews help track where the trip starts and where it ends.

Floor-Aware Routing

The UI accepts both segmented routes and per-floor route dictionaries. It automatically favors the destination floor when route data or room naming gives a reliable floor hint.

Practical note: if a room name is easier to remember than its exact internal ID, the UI still tries to normalize the location name so the search form, room list, and route map stay in sync.
Builder Manual

How to Use the Layout Builder

  1. Click Admin Login, enter valid credentials, and open Layout Builder. A successful login redirects to /#/configurator.
  2. Confirm the loaded map at the top of the screen. The builder shows a Loaded badge with the active layout name and filename.
  3. Choose a floor from the left side FLOOR 1, FLOOR 2, and FLOOR 3 buttons, or add a new floor by copying the current top floor.
  4. Add geometry with the toolbar buttons such as ADD ROOM, ADD LOUNGE, ADD STAIRS, ADD HALLWAY, ADD ENTRANCE, or ADD GREY SLAB.
  5. Draw on the canvas. New items snap to the grid. Existing items can be clicked, dragged, resized, recolored, relabeled, or deleted.
  6. Use the Properties panel to edit IDs, label text, type, wing, room color, hallway orientation, and exact geometry values.
  7. Save work with SAVE DRAFT if the map is still in progress, or use Publish when the layout is ready for the live search screen.

Canvas Editing Rules

The canvas uses grid snapping for drawing and movement. Hallways support constrained resizing and can be rotated from the properties panel. Gray slabs represent wing backgrounds and can be assigned to Wing A, B, or C.

Selection Behavior

Click any component to select it. Multi-select is supported with modifier keys, selected items can be moved together, and the right side delete control changes between deleting the selected component and deleting the active floor.

Draft and Publish

Map Layouts, History, Import, Export, and Release Flow

Map Layouts Window

The MAP LAYOUTS button opens the layout browser. From there, admins can load the current main layout, open draft files, inspect history snapshots, rename entries, and delete draft maps.

Draft Saves

SAVE DRAFT stores the current builder state as a draft payload. Existing loaded draft files can be updated in place, while new saves create new draft files and keep the workspace recoverable before publish.

JSON Import and Export

Export downloads either the main map layout JSON or a draft-style payload, depending on what is currently loaded. Import accepts JSON and applies it to the editor for the active floor or layout context.

Publish Behavior

Publish sends the current layout to the map layout publish endpoint, reloads the builder from the exact published payload, flags the search UI to refresh its map data, and attempts a UI backup save.

Release reminder: publishing is the step that moves builder edits into the live navigation experience. Draft saves preserve work, but users on the search page will not see those changes until publish succeeds.
Shortcuts

Keyboard and Editing Shortcuts

Ctrl + Z or Cmd + Z: Undo the last builder change.
Ctrl + C or Cmd + C: Copy the selected builder element or group.
Ctrl + V or Cmd + V: Paste copied elements.
Delete or Backspace: Remove the current selection.
Arrow Keys: Nudge selected items. Regular spaces move by the grid size; holding Shift uses smaller steps.
Enter: Commit property field edits such as IDs and coordinates.
Esc: Cancel the current draft drawing box in the builder or close suggestion focus states in search.
Operational Notes

Admin and Session Behavior

Session Rules

Admin sessions last for 8 hours. When the session expires, the UI logs the admin out, shows a session expired notice, and protects the configurator route from unauthenticated access.

Password Maintenance

Logged-in admins can open the password-change flow from the top navigation controls. Successful password changes can require a fresh login before editing continues.
