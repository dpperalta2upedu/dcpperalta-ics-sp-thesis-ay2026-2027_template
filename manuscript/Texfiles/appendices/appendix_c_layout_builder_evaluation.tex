\chapter[LAYOUT BUILDER EVALUATION QUESTIONS]{Layout Builder Evaluation Questions}\label{app:C}

The following open-ended questions were answered by the building administrators.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Which parts of the layout builder felt easy to understand, and which parts
  felt unnecessarily complex?
\item
  Can you describe your experience creating or editing a building layout using
  the system?
\item
  How well did the different features of the layout builder work together while
  you were making changes?
\item
  Were there any parts of the layout builder that felt confusing or difficult to
  predict? Please explain.
\item
  How confident did you feel that the layout you created or edited was correct
  and usable for navigation?
\item
  Would you like to use this application in the future?
\item
  What suggestions do you have to improve the layout builder so administrators
  can create more accurate and reliable maps?
\end{enumerate}
