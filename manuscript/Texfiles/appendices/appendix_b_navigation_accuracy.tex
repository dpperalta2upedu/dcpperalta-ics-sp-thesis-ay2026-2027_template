\chapter[NAVIGATION ACCURACY QUESTIONS]{Navigation Accuracy Questions}\label{app:B}

The following open-ended questions were answered by the regular users.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Did the application lead you to the correct destination? Describe what
  happened during the navigation process.
\item
  Was the route provided by the application accurate? Explain why or why not.
\item
  How easy was it to understand the route displayed on the map?
\item
  Were there any parts of the route that were confusing, unclear, or incorrect?
  If yes, describe them.
\item
  Did you encounter any mismatch between the route shown by the application and
  the actual path that should be taken inside the building? If yes, describe the
  mismatch.
\item
  What suggestions can you provide to improve the navigation accuracy of the
  application?
\end{enumerate}
