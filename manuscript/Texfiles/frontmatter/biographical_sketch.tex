\frontchapter{Biographical Sketch}

Dave Christian P. Peralta is a senior student currently pursuing a Bachelor of
Science in Computer Science at the Institute of Computer Science, University of
the Philippines Los Baños. His academic interests include software development,
system analysis, and cloud computing technologies and adoption. His
undergraduate special problem involves the creation of a 3D map layout of the
Physical Science Building inside the University of the Philippines Los Baños to
allow users to navigate inside the building with accurate and optimized routing,
along with the implementation of a map layout builder which makes it possible to
create map layouts for other buildings.
